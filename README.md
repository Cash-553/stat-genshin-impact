# 🍃 StatGI — 原神挂机收益统计器

**StatGI** 是一个 Windows 桌面工具，通过 **屏幕捕捉 + OCR 文字识别**，自动统计原神挂机打怪期间的收益（摩拉 / 材料 / 圣遗物·狗粮）。

> 不读取游戏内存、不注入、不修改游戏 —— 仅识别屏幕上的拾取提示，安全、稳定，适合长期挂机与直播场景。

当前版本：**v0.7**

---

## 📸 界面

- 无边框窗口 + 侧边栏导航 + 卡片式布局，Win11 自动圆角
- 深色主题，**背景色 / 强调色**可选（5 组预设 + 自定义取色）
- **自定义背景图片**：整个界面是半透明「玻璃」效果，底图从卡片缝隙透出来
  - 卡片透明度（卡片 / 侧边栏 / 按钮统一一个滑杆）
  - 背景压暗（照片类背景图看不清字时使用）
  - 左侧栏毛玻璃（模糊 + 压暗）
- **收益统计条**：直播间小窗口，摩拉 / 材料 / 狗粮三格，图标可换、可置顶、可调透明度

## 🧠 技术方案

- **语言 / 框架**：Python + Tkinter / CustomTkinter
- **屏幕捕捉**：`PrintWindow`（只截取游戏窗口内容，覆盖层不会混入）
- **文字识别**：`RapidOCR`（中文离线识别，无需 GPU）
- **打包**：PyInstaller（文件夹版，免安装 Python 环境，约 112 MB）

### 核心流程

```
只采集原神游戏窗口内容（PrintWindow，BetterGI 等覆盖层不进入）
  → 画面变化检测（无变化跳过，节省 CPU）
  → OCR 文字识别（"摩拉 ×200" / "破损的面具 ×2"）
  → 拾取提示 Track 去重（同一提示只统计一次）
  → 写入今日收益（本地 JSON 存档）
  → 推给界面 / 收益统计条 / 直播接口
```

### 关于「半透明玻璃」界面

CustomTkinter 没有真正的透明：每个控件都会用一层纯色盖住自己的区域（连文字标签内部都自带一块不透明底色），`fg_color="transparent"` 也只是「填父容器的颜色」。

所以这里的做法是**把背景图按位置切片贴进每个控件内部**：

1. 按控件所在位置从背景图上裁出对应的一块，按「卡片透明度」和控件自身颜色混合；
2. 贴回控件内部 —— 压过控件自己的底色层，但在文字 / 图标之下；
3. 卡片按 `corner_radius` 生成圆角遮罩，圆角外面补上「底下一层」的玻璃图，保证是圆角而不是直角；
4. 文字标签用 tk 的「图片 + 文字」叠放，把该位置的玻璃图铺满标签、文字叠在上面，底色就完全看不到了；
5. 开关 / 滑块的轨道是画在画布上的实色图形，改成「轨道色 × 该处背景」的混合色，看起来就是半透明。

## 📁 目录结构（源码）

```
├─ app.py                    主程序（主窗口 + 主循环）

│  ── 界面（按功能拆开，运行时通过 mixin 组合成 MainApp）──
├─ ui_base.py                公共常量与小工具（主题色、字体、热键键名转换）
├─ win_shell.py              窗口底层（无边框拖动/缩放、任务栏、圆角、热键、托盘）
├─ ui_glass.py               自定义背景 + 半透明玻璃界面
├─ ui_pages.py               各页面搭建 + 卡片工厂 + 页面切换
├─ ui_settings.py            设置读写 + 设置项回调 + 开发者选项
├─ ui_actions.py             清空 / 记录 / 材料 / 检查更新 / 统计条 / 接口
├─ ui_monitor.py             主循环 + 监测控制 + 界面刷新
├─ ui_widgets.py             自定义控件（浮动下拉框 / 折叠区）
├─ theme.py                  统一主题配色
├─ fonts.py                  字体检测与共享

│  ── 识别与数据 ──
├─ detector.py               检测流水线（文字识别 + 拾取提示去重）
├─ ocr_engine.py             OCR 引擎（RapidOCR 封装）
├─ capture.py                屏幕捕捉（mss 抓取指定区域）
├─ printwindow_capture.py    只采集游戏窗口内容（PrintWindow）
├─ main_ui_model.py          AI 主界面判断（ONNX Runtime 推理，不依赖 torch）
├─ region_selector.py        识别区域框选
├─ stats.py                  每日统计
├─ sessions.py               监测记录（每段挂机的收益）
├─ materials_db.py           材料数据库
├─ generated_names.py        材料（574）/ 圣遗物（299）名单
├─ dataset_collector.py      本地 AI 样本采集（开发者选项，默认关闭）

│  ── 周边 ──
├─ overlay_bar.py            横向收益统计条
├─ icon_manager.py           统计条图标管理
├─ tray.py                   系统托盘
├─ api_server.py             直播数据接口（Flask）
├─ config_manager.py         设置读写（config/settings.json）
├─ errlog.py                 出错记录（写 data/error.log）
└─ paths.py                  路径工具（源码运行 / 打包运行）
```
