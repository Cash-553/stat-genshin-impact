# StatGI — 原神挂机收益统计

通过屏幕识别统计原神挂机收益：**摩拉 / 材料 / 圣遗物（狗粮）**。

不读取游戏内存、不注入、不修改游戏，仅识别屏幕上的拾取提示。

---

## 下载

* **GitHub**：Releases 页下载完整压缩包，解压即用
* **Gitee**：Releases 页下载 `part1` + `part2` + `一键安装.bat`，三个文件放同一目录，双击 `一键安装.bat` 自动合并解压

原有设置、收益记录与收藏夹均可直接沿用。

---

## 功能

| 功能 | 说明 |
| --- | --- |
| 摩拉统计 | 识别「摩拉 ×200」自动累计 |
| 材料统计 | 按名称统计；内置材料库，未登记的名字自动收录 |
| 圣遗物（狗粮） | 出现即计数 |
| 防重复统计 | 同一条拾取提示只统计一次 |
| 只采集游戏窗口 | 叠加在游戏上的其它程序提示不会混入 |
| 前台识别 | 切到其它窗口自动暂停，切回自动继续 |
| 今日统计 | 自动换日归档、本地保存；换日时间可设 |
| 监测记录 | 每次「开始 → 停止」生成一条记录，可回看每段收益 |
| 收益记录 / 统计条 | 按月查看柱状图；直播间小窗口实时显示 |
| 定时启动（实验） | 按计划启动 BetterGI / 直播 / 挂机；支持配置组联动与定时关机 |
| 模块仓库 | 浏览并下载模块；已装模块支持一键更新 |
| 备份与恢复 | 设置、记录、名单一键打包；换电脑直接导入 |
| 性能档位 | 性能 / 标准 / 省电 / 极致省电 四档 |

---

## 使用

1. 解压后运行 `StatGI.exe`
2. 在「识别」页选中原神窗口，点一次试识别
3. 回到主界面点「开始监测」
